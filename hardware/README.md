# Hardware

Mechanical drawings, CAD and printable parts (cell mount cups, enclosures) will live here, one folder per phase:

- `bench-pad/` — phase 1, ~200 kg bench pad
- `full-size-pad/` — phases 2–3, ~2,000 kg car pad

Until then, the design is described in [docs/plan.md](../docs/plan.md) and [docs/assembly.md](../docs/assembly.md).
